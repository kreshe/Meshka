## 🚀 Описание проекта

**MESHKA (me)** — это универсальный консольный инструмент для автоматизации производственного тестирования и обслуживания устройств через UART.

Скрипт предназначен для работы с несколькими последовательными портами одновременно (`/dev/ttyUSB*`) и позволяет:

* выполнять автоматический вход на устройства;
* запускать прошивку;
* запускать наборы тестов;
* проверять аппаратные компоненты;
* открывать несколько UART-консолей через `minicom`;
* управлять режимами работы станции;
* выполнять стресс-тесты;
* контролировать состояние UART-портов в реальном времени.

Проект создан для использования на производственных и тестовых стендах.

---

# ✨ Возможности

## 🔌 Управление UART

MESHKA автоматически обнаруживает подключенные UART устройства:

```
/dev/ttyUSB0
/dev/ttyUSB1
/dev/ttyUSB2
...
```

Поддерживается:

* несколько устройств одновременно;
* параллельная отправка команд;
* контроль занятости портов;
* обнаружение открытых `minicom`;
* автоматическое восстановление UART.

Пример отображения:

```
┌──────────┬───────────┬────────────┐
│ Порт     │ Статус    │ Владелец   │
├──────────┼───────────┼────────────┤
│ ttyUSB0  │ 🟢 ОТКРЫТ │ minicom    │
│ ttyUSB1  │ ⚪ СВОБОДЕН│ —          │
│ ttyUSB2  │ 🔴 ЗАНЯТ  │ python     │
└──────────┴───────────┴────────────┘
```

# ⚙️ Режимы работы

При первом запуске MESHKA предлагает выбрать режим.

## 1. Прошивка

```
MODE=flash
```

Используется для производственной прошивки устройств.

После входа выполняется:

```
custom-installer
```

---

## 2. Проверка

```
MODE=check
```

Используется для запуска диагностических тестов.

---

## 3. Проверка SD

```
MODE=check_SD
```

Запускает проверку скорости и стабильности SD-карты:

```
dd if=/dev/zero \
of=/dev/mmcblk1 \
bs=1M \
count=2000 \
status=progress \
oflag=direct
```

# 🔐 Автоматический вход

MESHKA умеет автоматически входить в Linux-консоли устройств.

По умолчанию:

```
LOGIN=root
PASSWORD=root
BAUDRATE=1500000
```

Можно изменить:

```bash
export LOGIN=user1
export PASSWORD=password1
export BAUDRATE=115200
```

# 🖥️ Работа с minicom

MESHKA автоматически открывает UART терминалы.

Поддерживаются:

* gnome-terminal
* konsole
* xfce4-terminal
* xterm

Пример:

```
minicom → /dev/ttyUSB0
minicom → /dev/ttyUSB1
```

---

# 🔧 Настройка портов

По умолчанию:

```bash
PORT_GLOB=/dev/ttyUSB*
```

Можно указать вручную:

```bash
export ME_PORTS="/dev/ttyUSB0 /dev/ttyUSB2"
```

# 🔄 Восстановление UART

Команда:

```
u
```

Выполняет:

* закрытие своих minicom;
* повторное обнаружение устройств;
* обновление списка UART;
* повторное открытие терминалов.

# ⚡ Параллельная работа

Все команды отправляются одновременно:

```
ttyUSB0 ──┐
ttyUSB1 ──┼── MESHKA
ttyUSB2 ──┘
```

Это позволяет тестировать несколько устройств одновременно.
